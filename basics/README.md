# Python Basics

This folder contains practice exercises covering the fundamental concepts of Python.

## Topics Covered

* Variables and data types
* Operators
* String manipulation
* Conditional statements (`if`, `elif`, `else`)

## Practice Exercises

* Personal profile
* Simple calculator
* Temperature converter
* Swapping values
* Shopping bill
* Even or odd
* Number comparison
* String reversal
* Palindrome checker
* Grade calculator
* Login simulation
* Triangle classifier
* And more

## Goal

Build a strong foundation in Python syntax, logical thinking, and problem-solving through hands-on practice.
