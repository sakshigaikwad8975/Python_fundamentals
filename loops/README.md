# Python Loops

This folder contains practice exercises focused on repetition, iteration, and solving problems using loops.

## Topics Covered

* `for` loops
* `while` loops
* Nested loops
* Loop control
* Iterative problem-solving

## Practice Exercises

* Multiplication table
* Sum of natural numbers
* Factorial calculator
* Prime number checker
* Number guessing game
* Fibonacci sequence
* Pattern printing
* Digital root
* Bubble sort
* Console-based banking system

## Goal

Develop logical thinking and learn how to automate repetitive tasks and implement basic algorithms using loops.
