# Python Mini Projects

This folder contains small projects that combine Python fundamentals to solve practical problems.

## Projects

* **Student Performance Dashboard:** Manage student records, calculate averages, assign grades, and summarize class performance.
* **Personal Expense Manager:** Track expenses, categorize spending, and calculate spending summaries.
* **Quiz Application:** Create a multiple-choice quiz, track scores, and display results.
* **Password Strength Evaluator:** Analyze passwords based on length, character types, and basic security rules.
* **Library Management System:** Manage books, borrowing, returning, and availability.
* **Data Cleaning Pipeline:** Clean records, identify invalid data, and remove duplicates.
* **Mini E-commerce Cart:** Manage products, quantities, stock, discounts, and bills.
* **Text-Based Adventure Game:** Build an interactive game with choices, inventory, and different outcomes.
* **Basic Data Analysis:** Calculate mean, median, mode, range, and variance without external libraries.
* **Command-Line Task Manager:** Create, update, complete, and delete tasks.

## Goal

Apply Python fundamentals to build functional programs, strengthen problem-solving skills, and gain experience combining multiple concepts into complete solutions.
